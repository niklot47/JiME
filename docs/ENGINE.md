# Движок (`packages/engine`)

Интерпретатор сценариев FFG: семантика PlayMaker FSM поверх prefab-данных, плюс упрощённые поле, враги и раунды.
Без UI и без Node-зависимостей в ядре: данные приходят через интерфейс `ContentSource`.

## Файлы

| Файл | Что |
|---|---|
| `src/game.ts` | `Fsm`, объекты сцены (`Obj`, `Tile`, `GameNode`, `EnemyGroup`), `Game` (сцена, карта, маршрутизация событий, раунды), `Bot` |
| `src/actions.ts` | Обработчики действий FSM: имя действия PlayMaker → поведение |
| `src/pyrandom.ts` | ГСЧ, бит-в-бит совместимый с Python `random.Random` (MT19937) |
| `src/ojson.ts` | JSON-парсер с сохранением порядка числовых ключей (`keysOf`/`valuesOf`) |
| `src/py.ts` | Семантика Python: истинность, `str()`, `int()`, `dict.get` |
| `src/node/packSource.ts` | Чтение пака с диска (только Node) |
| `cli/run.ts` | Одна партия бота, лог формата LogA |
| `cli/fuzz-all.ts` | Все приключения × N сидов: ошибки, покрытие, предупреждения |
| `cli/parity.ts` | Сверка с `engine-py` по тем же сидам |

## Паритет с Python (Этап 2.1)

TS-движок — построчный перенос `engine-py/engine.py`. Одинаковое поведение при одном сиде:

- ГСЧ совместим с CPython;
- словари обходятся в порядке файла, как в Python;
- истинность и приведения — по правилам Python.

`pnpm parity` сравнивает:

- полный лог;
- исход, раунд, угрозу;
- предупреждения и нереализованные действия;
- покрытие состояний FSM;
- итог кампании.

Результат на 13.10.2026: **3315 из 3315 партий идентичны** (72 приключения × 35 сидов + A1–A3 × 265 сидов).

### Правила

- Пока `engine-py` — эталон, семантику менять **в обоих движках сразу** и прогонять `pnpm parity`.
- Когда TS начнёт уходить вперёд (точная карта, бой — Этап 2.3), `engine-py` замораживается, а паритет заменяется собственными тестами и фаззером.
- Тесты в `test/` используют синтетические сценарии: в CI нет данных FFG.

## Команды

```bash
pnpm play 1 7          # партия A1, сид 7
pnpm fuzz              # 72 приключения × 10 сидов (~10 с)
pnpm parity            # сверка с Python, 72 × 5 сидов
node packages/engine/cli/parity.ts 1,2,3 0 300   # выборочно
```
