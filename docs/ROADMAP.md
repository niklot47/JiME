# План реализации

Стек: **TypeScript + Tauri 2**. 3D — Three.js, UI — React.
Движок — отдельный пакет без UI. Всё заменяемое — паки с приоритетами.
Импортёр остаётся на Python: на JS нет надёжного читателя ассетов Unity.
