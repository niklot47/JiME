# План реализации

Стек: **TypeScript + Tauri 2**. 3D — Three.js, UI — React.
Движок — отдельный пакет без UI. Всё заменяемое — паки с приоритетами.
Импортёр остаётся на Python: на JS нет надёжного читателя ассетов Unity.

Статусы: ✅ готово · 🔄 в работе · ⏳ дальше · 💡 идея

## Этап 1 — Основа репозитория 🔄
1. ✅ Монорепо (pnpm 10 workspaces):
   - `packages/schema`, `packages/engine`, `packages/content-tools`;
   - `apps/app` (Tauri 2 + React 18 + Vite 6): каркас, иконки, сборка фронтенда проверена в VM;
   - `tools/importer` (Python).
   - TS запускается без сборки (Node ≥ 22.18, type stripping), тесты — `node --test`.
2. ✅ **Формат пака** `pack.json` (`docs/PACKS.md`): id, версия, приоритет, зависимости, `origin`. Слои: зависимости → приоритет. Типы `scenario`, `lang` работают; `voice`, `theme`, `models`, `rules` — только в схеме.
3. ✅ JSON Schema: `pack`, `scenario` (конверт над FFG prefab+FSM), `db`; `formatVersion: 1`. `make_pack.py` пишет `data/packs/core-ffg`: 72 + 680 сценариев, en/ru/it. Валидация: 753 файла, 0 ошибок.
4. 🔄 CI-скрипты:
   - ✅ `pnpm test` — 12 тестов;
   - ✅ `pnpm fuzz` — пока обёртка над `engine-py`;
   - ⏳ GitHub Actions;
   - ✅ Windows: `pnpm install`, `pnpm test`, `pnpm dev`, `pnpm tauri dev` работают (Rust + VS Build Tools C++).

## Этап 2 — Движок на TypeScript ⏳
1. Перенос `engine-py` в `packages/engine`:
   - FSM-рантайм, обработчики действий, состояние игры;
   - ГСЧ с сидом (воспроизводимость), лог событий, сохранение и загрузка.
2. Бот и фаззер на TS. Паритет с Python-версией по метрикам: покрытие, ключи, исходы.
3. Точность:
   - **генератор карты как в MapBuilder/SectionBuilder** — гекс-геометрия, повороты, стыковка тайлов;
   - позиции объектов (MoveNode, RandomSpace, GetTileId);
   - условия активаций врагов, урон и ключевые слова, последний рубеж;
   - тьма, тайм-ауты.
4. Кампания: цепочка приключений, перенос флагов, опыт и лор, предметы, звания, отдых между приключениями.
5. Боевые карты: Battleboard, терренные узлы, точки появления.

## Этап 3 — Приложение (игра) ⏳
1. Каркас Tauri: менеджер паков, первый запуск = мастер импорта (указать папку игры → запуск импортёра).
2. Экран игры:
   - поле Three.js (из прототипа);
   - сообщения, проверки, выборы, лог;
   - трекер врагов, угроза, раунд/фаза.
3. Меню: кампании, слоты сохранений, выбор героев и ролей, сложность.
4. Отдых: инвентарь, навыки и колоды, роли, опыт.
5. Локализация интерфейса и контента: ru/it/en + паки языков для DLC без перевода.
6. Темы: CSS-переменные + картинки из пака; тема «Оригинал» собирается из ассетов FFG при импорте.
7. Звук: музыка и эффекты из ассетов; озвучка по ключам из voice-пака.

## Этап 4 — Редактор ⏳
1. Редактор сценария внутри приложения:
   - граф состояний (React Flow);
   - формы действий со справкой;
   - карта секций и тайлов.
2. Предпросмотр: запуск сценария в движке с ботом и пошаговым режимом.
3. Валидация: схема + фаззер (тупики, недостижимые состояния, неиспользуемые тексты).
4. Экспорт и импорт пака сценария.
